# 코인 이동평균선 텔레그램 알림

업비트 공개 API(무료, 키 불필요)로 **비트코인·이더리움·솔라나·리플·에이다·도지코인**과 나만의 지표 **알트 지수**의 가격을 **1시간마다** 확인하고, **60일선·120일선을 상향 돌파 / 하향 이탈**하면 텔레그램으로 알립니다. **Firebase Cloud Functions(Python) + Cloud Scheduler**로 실행하고, 알림 상태(쿨다운)는 **Firestore**에 저장합니다.

## 감시 대상 (7개)

| 대상 | 내용 |
|---|---|
| BTC, ETH, SOL, XRP, ADA, DOGE | 업비트 KRW 마켓 현재가 |
| **알트 지수** | BTC를 뺀 5개 코인(ETH·SOL·XRP·ADA·DOGE)의 동일 비중 평균 |

### 알트 지수 계산 방식
원화 가격을 그대로 평균내면 ETH(수백만 원)가 DOGE(수백 원)를 압도하므로, 각 코인을 **일봉 윈도 첫날 = 100**으로 정규화한 뒤 5개를 평균냅니다. 이렇게 하면 5개 코인의 등락이 똑같은 비중으로 반영됩니다. 값의 단위는 `pt`이고, 이동평균선도 이 지수값에 대해 계산합니다. (구성 코인은 `config.yaml`의 `custom_index.members`에서 바꿉니다.)

## 알림 조건

| 조건 | 기준 |
|---|---|
| 60일선 | 현재가가 **60일 이동평균선** 상향 돌파 / 하향 이탈 |
| 120일선 | 현재가가 **120일 이동평균선** 상향 돌파 / 하향 이탈 |

- 이동평균은 업비트 **일봉 종가** 기준이며, 오늘 봉은 현재가로 대체합니다. (업비트 일봉은 09:00 KST에 바뀝니다.)
- 판정: **어제 종가가 이평선 이하였는데 현재가가 위**면 상향 돌파, **어제 종가가 이평선 위였는데 현재가가 아래**면 하향 이탈입니다.
- 동일 신호는 최초 발생 후 **12시간** 억제되며, 방향이 반대로 바뀌면 즉시 알립니다.
- 매매 신호, RSI, 등락률 알림은 넣지 않았습니다.

```
🪙 코인 이동평균선 알림 (2026-10-03 16:00 KST)

· 비트코인 (BTC)
	🟢 60일선 상향 돌파 → 현재 115,115,000원 > 60일선 114,800,000원
· 알트 지수 (ETH+SOL+XRP+ADA+DOGE)
	🔴 120일선 하향 이탈 → 현재 98.12pt < 120일선 99.40pt
```

코인은 24시간 거래라 장 시간·휴장일 로직 없이 **매시 정각(KST)** 실행합니다.

## 설정 순서

### 1. 텔레그램 봇 + 새 채팅방
기존 주식 봇을 재사용해도 되지만, **새 채팅방**으로 받으려면 아래처럼 합니다.

1. (선택) `@BotFather` → `/newbot` → 새 봇을 만들어 **토큰**을 받습니다. 주식 봇을 재사용하면 이 단계는 건너뛰고 기존 토큰을 씁니다. 두 알림을 채팅방으로 분리하는 것이 목적이면 봇은 같아도 됩니다.
2. 텔레그램에서 **새 그룹 만들기**(또는 채널) → 멤버로 위 봇을 추가합니다. (1:1 채팅이 아닌 새 방이 필요할 때)
   - 나 혼자 쓸 거면 새 봇을 만들어 그 봇과의 1:1 대화창을 쓰는 것이 가장 간단합니다.
3. 방에서 아무 메시지나 보냅니다. (그룹이면 `/start@봇이름` 또는 봇을 멘션)
4. `https://api.telegram.org/bot<토큰>/getUpdates` 접속 → `chat.id`가 **채팅 ID**입니다.
   - 그룹의 chat.id는 **음수**(예: `-1001234567890`)입니다. 그대로 사용합니다.
   - 결과가 비어 있으면 방에서 메시지를 다시 보낸 뒤 새로고침합니다. 그룹에서 봇이 메시지를 못 받으면 BotFather → `/mybots` → Bot Settings → Group Privacy를 **Turn off** 합니다.

### 2. Firebase 프로젝트 (새 프로젝트)
1. [Firebase 콘솔](https://console.firebase.google.com)에서 **새 프로젝트** 생성
2. **Blaze(종량제)** 로 업그레이드 (Cloud Scheduler 필요, 실사용량은 대부분 무료 한도 내)
3. **Firestore Database 생성** (네이티브 모드, **기본 `(default)` 데이터베이스**)
4. `npm install -g firebase-tools` → `firebase login`
5. 이 폴더에서 `firebase use --add`로 프로젝트 선택 (또는 `.firebaserc`의 `REPLACE_WITH_YOUR_FIREBASE_PROJECT_ID`를 직접 수정)

### 3. 시크릿 등록
```bash
firebase functions:secrets:set TELEGRAM_BOT_TOKEN
firebase functions:secrets:set TELEGRAM_CHAT_ID
```

### 4. 배포
```bash
firebase deploy --only functions
```
`coin_alert_job` 스케줄이 등록되어 매시 정각(KST)에 실행됩니다. `config.yaml`이나 코드를 바꾸면 다시 배포해야 반영됩니다.

## 로컬 테스트

텔레그램·Firestore 없이 실제 업비트 데이터로 판정만 확인합니다.

```bash
cd functions
pip install pandas requests PyYAML
DRY_RUN=1 python coin_alert.py          # PowerShell: $env:DRY_RUN=1; python coin_alert.py
```

## 알아둘 점
- **요청 제한**: 업비트 시세 API는 IP당 초당 약 10회입니다. 실행당 호출은 7회 정도이고 429 응답 시 자동 재시도합니다.
- **데이터 길이**: 일봉 200개를 받아 120일선을 계산합니다. 상장 후 120일이 안 된 코인은 해당 조건이 자동 제외됩니다.
- **원화 기준**: 달러 가격이나 김치 프리미엄은 반영하지 않습니다.
- 이 알림은 참고 정보이며, 투자 판단과 결과는 본인 책임입니다.
